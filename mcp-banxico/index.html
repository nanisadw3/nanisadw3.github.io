Remote MCP server

Official Mexican economic data,
straight from Banxico

Connect Claude, Cursor, or any MCP client to the Banco de México SIE API — the authoritative source, not a scraper or a third-party mirror. Every answer carries its cut-off date and the official series id, so you can audit it.

Endpoint https://banxico-mcp.duckdns.org/mcp No signup · No API key

What it reads

Six read-only tools over nine official series from the Sistema de Información Económica.

tipo_cambio_usd

USD/MXN exchange rate, both FIX and settlement (liquidación) modalities, with optional date ranges.

inflacion_mexico

Inflation from the INPC, annual or monthly.

valor_udis

UDIS value for any given date.

tasa_interes_banxico

TIIE 28-day interbank rate and the central bank's target rate.

reservas_internacionales

Net international reserves, in millions of US dollars.

consultar_serie_sie

Any other series in the SIE catalog, by its identifier.

Connect in one line

The hosted endpoint speaks Streamable HTTP and needs no credentials.

claude mcp add --transport http banxico https://banxico-mcp.duckdns.org/mcp

Or point any MCP client at the URL directly:

{
  "mcpServers": {
    "banxico": {
      "type": "http",
      "url": "https://banxico-mcp.duckdns.org/mcp"
    }
  }
}

Run it yourself

Prefer your own instance and your own quota? It is a Python package, and the token is free and self-service from Banxico.

uvx mcp-banxico
{
  "mcpServers": {
    "banxico": {
      "command": "uvx",
      "args": ["mcp-banxico"],
      "env": { "BANXICO_TOKEN": "your-free-sie-token" }
    }
  }
}
Get a token at Banxico's SIE portal — it is free and takes about a minute.
