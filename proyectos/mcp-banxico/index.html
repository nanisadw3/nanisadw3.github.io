El tipo de cambio lo pide esta página a mcp-banxico en tiempo real.

Problema

Los asistentes de IA no saben cuánto vale hoy el dólar. Si les preguntas por el tipo de cambio, la inflación o las UDIS, responden con datos viejos de su entrenamiento o, peor, con un número inventado. Para cualquier uso financiero en México eso es inaceptable: la referencia oficial es el Banco de México, y una respuesta sin fuente ni fecha no sirve.

Solución

mcp-banxico es un servidor de Model Context Protocol que le da a cualquier cliente compatible (Claude Desktop, Cursor, Cline, Gemini CLI) acceso directo al Sistema de Información Económica (SIE) de Banxico. No es un scraper ni un espejo de terceros: consulta la fuente oficial y cada respuesta incluye la fecha de corte y el ID de la serie, así que se puede auditar.

Expone seis herramientas de solo lectura:

Herramienta Qué consulta
tipo_cambio_usd Tipo de cambio peso-dólar (FIX)
inflacion_mexico Inflación del INPC, anual o mensual
valor_udis Valor de la UDI
tasa_interes_banxico Tasa objetivo y TIIE
reservas_internacionales Reservas internacionales
consultar_serie_sie Cualquier serie del SIE por ID y rango de fechas

Arquitectura

Hay dos formas de usarlo:

  • Local, con uvx mcp-banxico o pip install mcp-banxico, usando el token gratuito del SIE. El cliente habla con el servidor por stdio (JSON-RPC).
  • Endpoint remoto público en https://banxico-mcp.duckdns.org/mcp, con transporte streamable-http. No requiere instalar nada ni sacar token; tiene límite de peticiones por IP y corre en infraestructura propia (Linux, Nginx y TLS).
{
  "mcpServers": {
    "banxico": {
      "type": "streamable-http",
      "url": "https://banxico-mcp.duckdns.org/mcp"
    }
  }
}

La página en vivo: Banxico al Día

Para que cualquiera vea los datos sin instalar nada, construí Banxico al Día sobre las mismas series que consulta el servidor MCP. Es una página pública con 22 indicadores oficiales (tipo de cambio de cinco monedas, tasa objetivo, TIIE, CETES, inflación, UDIS y reservas), cada uno con su gráfica, su histórico descargable en CSV y una lectura del día que se redacta sola a partir de los datos: cuánto cambió frente al día hábil anterior y en el último mes, en lenguaje sencillo.

Los datos se actualizan solos cada día hábil con una GitHub Action, después de que Banxico publica el FIX. El detalle técnico está en su caso de estudio.

Resultados

  • Descargas mensuales en PyPI en constante crecimiento (cifra en vivo arriba).
  • Incluido en la lista TensorBlock/awesome-mcp-servers.
  • Base de otros proyectos: Banxico al Día usa sus series, y el agente Gordito lo integra como herramienta.
  • Un video de diez minutos sin cortes muestra a un modelo local (Qwen 2.5 en Ollama) y a Claude Desktop pasar de “no tengo acceso en tiempo real” a responder con el tipo de cambio oficial.

Stack

Python 3.10+, SDK oficial de MCP, API REST del SIE de Banxico, publicación en PyPI, Nginx y Let’s Encrypt para el endpoint remoto.
